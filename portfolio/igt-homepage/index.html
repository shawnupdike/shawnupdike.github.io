Massive Overhaul

The IGT homepage redesign project involved a comprehensive overhaul of the existing website to create a more modern, user-friendly, and visually appealing experience.

Key features of the redesign included a clean and intuitive layout, improved navigation, and engaging visuals that effectively showcased IGT's products and services.

The redesign also focused on enhancing the overall user experience by incorporating responsive design principles to ensure optimal performance across all devices.

Data Driven & Design Lead

The redesign process was driven by user research and data analysis to identify pain points and areas for improvement on the existing homepage. Pain points included:

  • Clunky navigation making it difficult for users to find information quickly.
  • Content Priorities were unclear, leading to confusion about IGT's offerings.
  • Layout and structure were outdated, resulting in a less engaging user experience.
  • Web design best practices were not fully implemented, affecting usability and accessibility.
  • Stakeholders desired a fresh, modern look to better reflect IGT's brand identity.

Improvement Metrics

The redesign led to significant improvements in user engagement and satisfaction, as evidenced by the following metrics:

  • 171.5% YoY Overall Page Growth
  • 50%+ Increase in User Interaction
  • 20,000+ Increase in Click-Throughs
  • 25,000+ Increase in Page Views
