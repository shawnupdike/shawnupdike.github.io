Weather Challenge

Main goal was to create a simple, easy to use weather app that provided accurate and real-time weather information for the Greater Boston Area. The app had to have:

  • Mobile Responsive
  • Real-time Weather Data
  • Brand Identity
  • Balanced Design
  • Intuitive Navigation

Data Driven

The process of creating Smaht Weather involved several key steps to ensure a successful outcome:

  • Assemble a strong & humble branding image with a hint of New England verbiage humor to keep the user engage in a simple weather app.
  • Conducted user research to understand what features & data points users wanted to see in a weather app.
  • Sketche & wireframe used for testing, proof of concept for actual live weather data from an API.

Special title treatment

User testing concluded & improvements were made from feedback to enhance the app to be better for all users.

Smaht Weather is a real live working app that was built in HTML, CSS & Sass, pulled data from DarkSky API, animated and brought to life through After Effects and Javascript. Accomplishments from user feedback included:

  • Subtle Brand Humor Enjoyment
  • Excellent Functionality
  • Easy Navigation
  • Aspect Ratio Responsiveness
